# Mei Mei Birthday Website — free to publish

A small static birthday website made for Saniha / Mei Mei by Zohien.

## Preview on your computer
1. Unzip this folder.
2. Open `index.html` in Chrome, Edge, or another browser.
3. Keep the `photos` folder beside `index.html` and `style.css`.

## Publish free with GitHub Pages
1. Sign in or create a free account at https://github.com
2. Create a **new public repository** named `mei-mei-birthday`.
3. Upload `index.html`, `style.css`, `script.js`, and the whole `photos` folder (including all four JPGs).
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main**, folder **/(root)**, then press **Save**.
7. Wait a minute or two. GitHub will show your live website address in the Pages section.

## Make the QR code
Once the website is live, copy its full `https://...github.io/...` address and use a reputable free QR-code generator. Paste the URL, create the QR code, then test it by scanning with a second phone before sending/printing it.

## Personalise it
- Edit the birthday letter in `index.html`.
- Replace the photos in `photos/` if you want; keep the same filenames or update the image paths in `index.html`.
- The music button opens a Spotify search for “Reflections” by The Neighbourhood. The site does not host copyrighted audio.

## Privacy
The repository is public so GitHub Pages can host it free. Anyone with the site URL can view the page and photos. Only upload pictures you have permission to share. You can delete the repository after the birthday if you no longer want the page online.
